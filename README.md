# 포켓몬 도감 ZZang

React.js로 만든 포켓몬 도감 웹 애플리케이션입니다.

## 기술 스택

- React 18
- TypeScript
- Tailwind CSS
- React Router v6
- TanStack Query v5
- Zustand v5
- Vite

## 기능

- 1세대 포켓몬 151마리 조회
- 포켓몬 이름 검색
- 타입별 필터링
- 포켓몬 상세 정보 (스탯, 특성, 진화 체인)
- 반응형 디자인

## 시작하기

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 빌드
npm run build
```

## API

[PokeAPI](https://pokeapi.co/)를 사용합니다.
